# Contributing to SHOP.md

SHOP.md is an open standard. Contributions are welcome.

## What we accept

- Bug reports and clarifications on the spec (open an issue)
- New example implementations in examples/ (open a PR)
- Validator improvements (open a PR with tests)
- Translations of the spec (open an issue first to coordinate)

## What we do not accept

- Changes that make the spec Shopify-specific
- New required fields without a strong cross-platform use case
- Breaking changes to existing required fields without a major version bump

## Process

1. Open an issue describing the change before writing code or prose
2. Fork the repo and create a branch
3. Submit a PR referencing the issue
4. A maintainer will review within 7 days

## Code of conduct

Be direct. Be precise. No marketing language.
